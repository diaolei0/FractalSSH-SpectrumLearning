# Reference outputs

This directory is reserved for the final paper-consistent evaluation outputs.

Do not populate it with intermediate or legacy results. The source archive supplied for public-release preparation contained a small reference result set whose hybrid 9-class metrics did not exactly match the manuscript values, so those files are intentionally excluded from this clean release.

For the public paper release, copy the final outputs generated by `03_final_hybrid/RUN_FINAL_9CLASS.py` from the production run after confirming that they match the manuscript and Supplementary Materials exactly.
